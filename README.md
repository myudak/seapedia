# SEAPEDIA

SEAPEDIA is a full-stack multi-role marketplace for the Software Engineering Academy COMPFEST 18 assignment. Guests can browse 32 products and submit reviews; authenticated buyers, sellers, drivers, and admins operate one shared order lifecycle.

## Stack

- Next.js App Router, React, TypeScript, and Tailwind CSS
- Convex local database, queries, and atomic mutations
- Better Auth through `@convex-dev/better-auth`
- Zod validation at the Next.js route boundary
- Vitest unit and transaction-invariant tests
- First-party generated product photography under `public/assets/products`

## Local Setup

```bash
pnpm install
Copy-Item .env.example .env.local
pnpm exec convex dev
```

On first setup, choose `Start without an account (run Convex locally)`. Convex writes the deployment URLs to `.env.local`, stores persistent state under `.convex/local/default`, and generates `convex/_generated`.

Set backend-only values in the local deployment:

```bash
pnpm exec convex env set SITE_URL http://127.0.0.1:3001
pnpm exec convex env set BETTER_AUTH_SECRET <same-value-as-.env.local>
pnpm exec convex env set SEED_ACCOUNT_PASSWORD <same-value-as-.env.local>
pnpm exec convex run seed:seed
```

Start both services:

```bash
pnpm dev:local
```

- Storefront: `http://127.0.0.1:3001`
- Convex API: `http://127.0.0.1:3210`
- Local dashboard: `pnpm convex:dashboard`

The seed is idempotent. Re-running it updates stable accounts, stores, products, discounts, reviews, wallets, and system settings without duplicating records.

## Environment

| Variable | Purpose |
| --- | --- |
| `NEXT_PUBLIC_CONVEX_URL` | Convex client URL, normally `http://127.0.0.1:3210` |
| `NEXT_PUBLIC_CONVEX_SITE_URL` | Convex HTTP URL, normally `http://127.0.0.1:3211` |
| `CONVEX_DEPLOYMENT` | Local deployment identifier generated by the CLI |
| `SITE_URL` | Next.js origin trusted by Better Auth |
| `BETTER_AUTH_SECRET` | Better Auth signing secret, at least 32 characters |
| `SEED_ACCOUNT_PASSWORD` | Development-only password for seeded accounts |

Never commit `.env.local` or production credentials.

## Catalog

- 32 products: 8 each in Fashion, Food, Home, and Gadget
- 12 products per page with search, category filters, and sorting
- Sort options: popular, rating, lowest price, and highest price
- Stable public URLs use `/products/{publicId}`; Convex `_id` values remain internal
- Homepage merchandising shows the four featured products with the highest sold count
- Generated hero and gallery assets are optimized to `1200x1500` WebP; no embedded labels, fake logos, or watermarks

To add catalog assets, generate one distinct product image per item, optimize the selected result to WebP, save it under `public/assets/products/catalog` or `public/assets/products/gallery`, then reference that local URL from `src/lib/seed/public-products.ts`.

## Commerce Rules

- Cart items must come from one store.
- Checkout is one atomic Convex mutation: cart, store, stock, wallet, address, delivery, and discount validation happen before any write.
- PPN is 12% of the subtotal after discount.
- Delivery fees: Instant `Rp20.000`, Next Day `Rp12.000`, Regular `Rp8.000`.
- Voucher codes are percentage discounts with expiry and remaining usage. Promo codes are fixed-amount discounts with expiry. One code can be used per checkout.
- Checkout prevents negative stock and insufficient wallet balance.
- Sellers move paid orders to `Menunggu Pengirim`.
- Convex OCC prevents two drivers from claiming the same job.
- Drivers earn 80% of the delivery fee after completion.
- SLA: Instant 6 hours, Next Day 1 day, Regular 3 days.
- Admin overdue handling is idempotent: the wallet refund and stock restoration happen once.

## Routes

- `/` storefront and public reviews
- `/products` paginated catalog
- `/cart` and `/checkout` buyer flow
- `/dashboard` authenticated marketplace overview
- `/dashboard/buyer`, `/dashboard/seller`, `/dashboard/driver`, `/dashboard/admin`
- `/docs/api` API reference and `/openapi.json` OpenAPI summary
- `/security` authorization and safe-content checks

All `/api/*` responses retain the `{ ok, data, error }` envelope. Marketplace state is sourced from Convex; `src/lib/domain/state.ts` is retained only for isolated legacy calculation tests and is not imported by runtime routes or pages.
